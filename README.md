# SITUATION_resources

D&D 5e（フォーゴトン・レルム）のロールプレイで使う、悪役寄りのシチュエーション集です。プレイヤーに近い女性キャラクターや、旅先で出会った囚われ人が容赦のない敵NPCの手に落ち、プレイヤーが救う側に立つ場面を、1シチュエーション1ファイルのMarkdownで集めています。

AIは敵を「理由があって憎めない」人物にしがちなので、それを避けた敵の描き方をGMやAIに渡すための資料です。

## フォルダ構成

```
SITUATION_resources/
├── README.md        このファイル。リポジトリの構成説明
├── GUIDELINES.md    シチュエーションを書くときの方針（書く前に必ず読む）
├── situations/      プレイヤーに近い女性キャラクターが敵の手に落ちるシチュエーション
└── strangers/       プレイヤーと初対面の囚われ人を救うシチュエーション
```

## 各シチュエーションファイルの構成

ファイル名は `NNN_英語のスネークケース.md`（3桁の通し番号はフォルダごとに001から）です。中身はおおむね次の見出しで構成されます。

| 見出し | 内容 |
|---|---|
| `# タイトル` | シチュエーション名 |
| `## 揺さぶる感情` | プレイヤーに呼び起こしたい感情 |
| `## 骨子` | 状況の要点 |
| `## 前提条件` | 成立に必要な状況や敵の設定 |
| `## 発生の流れ` | 場面がどう始まり、どう進むか |
| `## 被害者の外見` | 彼女の姿（必要に応じて） |
| `## 演出のポイント` | GMが演じるときのコツ |
| `## アライメント別の振る舞い` | 9アライメントごとの彼女の反応（`strangers/` で必要に応じて） |
| `## 台詞例（原文）` | ユーザーが書いた台詞をそのまま載せたもの |
| `## 台詞例` | 敵や彼女の台詞の例 |
| `## 描写例` | 山場を地の文で書いた例（必要に応じて） |
| `## 救済の余地（GM向け）` | 彼女を救い出す道 |
| `## バリエーション` | 設定や展開の別案 |

台詞はどれも、場面やキャラクターに合わせて改変して使えます。ファイル内では特定のキャラクター名を使わず、「彼女」「<プレイヤー名>」と汎用的に書いています。

## 新しいシチュエーションを追加するには

1. `GUIDELINES.md` を読む
2. 該当フォルダの次の番号で `NNN_英語のスネークケース.md` を作る
3. 上の見出し構成に沿って書く
4. このREADMEの一覧表に1行追加する
